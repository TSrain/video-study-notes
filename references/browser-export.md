# 已安装扩展的导出操作

通过宿主当前可用的 computer use 操作。Codex 桌面可用原生 Chrome AX；其他环境按工具实际支持的浏览器 API 执行。不要硬编码 AX 序号、坐标、扩展 ID、Chrome 个人资料或某台电脑的安装目录。操作后重新读取状态；浏览器 DOM 接口不支持内部页时使用可用的原生界面操作，或指导用户手动完成。不得通过浏览器 profile/数据库读取扩展存储。

## 扩展识别

| 平台 | 界面名称 | 官方项目 |
| --- | --- | --- |
| B站 | Bili Digest 哔哩精读 / 打开 Bili Digest | https://github.com/B-LIPSTICK/bili-digest |
| YouTube | YouTube Digest / Open YouTube Digest | https://github.com/zarazhangrui/youtube-digest |

从当前机器的扩展管理页按名称识别并核对来源。缺失或配置未完成时，转到 [安装与配置](setup.md)。不要悄悄换成另一个同名或付费扩展，也不得用“插件生成的摘要”代替原始字幕。

## B站：Bili Digest

1. 普通 `/video/BV…` 页面，在浏览器保留现有 B站登录态。`p` 是分 P；“合集第几个视频”未必是该 BV 的分 P，不要混淆。
2. 点击工具栏“打开 Bili Digest”（页面“精读”也可）。侧边栏核对标题、BV、分集，再点“字幕”。
3. 选择“原文”，等待“已加载 N 条字幕 · 语言”。记录 N。不要点“翻译”。
4. 点 **“导出资料”**（帮助文字通常为“字幕、笔记，不含 AI 概览”），不要点“导出含 AI 概览”。默认是 `<视频标题>-<分集标题>.md`，多分集可能带后缀；以实际下载记录为准。
5. 下载可能直接进入 用户当前下载目录（常见为 `~/Downloads` 或 `%USERPROFILE%\Downloads`，以浏览器下载记录为准），也可能弹出保存面板。弹窗时填写本次可写目录；直接下载时从浏览器的下载记录获得**准确文件名**，在文件系统验证。文件冲突会出现 `(1)` 等后缀，不要误拿上一次文件。
6. 实际 Markdown 应包含 `# 视频标题`、BV/来源链接、`## 字幕` 和 `- [00:06] 原文` 等条目。其他区块可能含视频简介或用户笔记，正文处理时隔离它们。B站导出头可能没有 `p`，所以多 P 必须由 UI 与输出文件名共同核实，并向 helper 传 `--verified-part`。

## YouTube：YouTube Digest

1. 普通 `youtube.com/watch?v=…`，或在浏览器将 `youtu.be/…` 导航到标准视频页。不要将推荐视频/播放列表项错当目标视频。
2. 点工具栏“Open YouTube Digest”或页面“Digest”。核对侧栏标题与频道，等待“Fetching transcript”结束。Supadata 会获取已有字幕，可能消耗已有账户额度；不要反复重试。
3. 进入 **Transcript**，选 **Original**。这个版本的翻译按需调用 AI，提取原文不需要触发翻译。
4. 点 Transcript 顶部的 **Export**（不是 Overview 或 Notes 的导出）。默认文件名是 `<标题>-transcript.txt`。
5. 导出内容应包含 `Title:`、`Channel:`、`URL:` 与 `TRANSCRIPT:`，也可能包含 `DESCRIPTION:`。只用 `TRANSCRIPT:` 之后的实际字幕正文写笔记；简介不是字幕。
6. 当前源码导出的是正文 TXT，通常不带逐句时间戳。不能以为面板能跳转就声称 TXT 也有时间轴。使用本地正文段落/行号作引用；需要精确片段时额外在界面核实，不按比例编时间。

## 下载与文件验收

- 导出前记下开始时间，导出后看到“Done/完成”并核对新文件修改时间、大小、头部来源、正文和结尾。辅助脚本会校验视频 ID、原文字节 SHA、B站条数与时间顺序，但不能替代 UI 来源核对。
- 原始下载在 用户当前下载目录（常见为 `~/Downloads` 或 `%USERPROFILE%\Downloads`，以浏览器下载记录为准） 时，只复制明确匹配本次下载记录的文件到学习目录；不要清理用户下载目录。原始导出保留原字节。
- 导出失败时可使用扩展自身的“复制字幕”，但要通过受支持的 UI 将剪贴板内容保存成实际本地文件，并补录界面核对的元数据。helper 目前只支持标准导出格式；复制文本不能伪装成标准导出、不能在无法核对时硬套 ingest。浏览器/剪贴板操作仍必须走 computer use 的接口。
- 没有字幕时不能根据观看页面标题编出学习笔记。API 错误文本、加载占位文字和空文件都不是字幕。
